# Provenance

The committed audit trail. Contains metadata only — no data, no personal data.

- `fetch_log.csv` — append-only. One row per file per raw fetch: URL,
  timestamp, HTTP status, ETag, bytes, row count, SHA-256, who fetched it.
  Rows are never edited or removed; a superseded snapshot stays in the log,
  which is the point.
- `dove_schema_<snapshot_id>.md` — what Dove's schema actually looked like at
  the moment the frame was built. Generated by `scripts/02_profile_dove.R`.
  When Dove changes fields under you, this file changes visibly in a diff.

The bytes these records describe live in `data/raw/`, which is untracked.
Anyone with this repo can verify a snapshot they have been given; nobody needs
the repo to contain the data.
