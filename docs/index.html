Each list has a companion .json manifest recording how and when it was generated, with a SHA-256 checksum. Once the questionnaire is live, a published list is never altered: a changed list is published under a new name.

Format

Plain UTF-8 text with Unix line endings. The first line is a header; every other line is one ring.

# <snapshot> <rings> <characters>
<RingID>|<display name>|<alternative names>

RingID is Dove's ring identifier. Alternative names help searching but are not shown. The header counts let the questionnaire detect a truncated or partly cached file.

What is included

Every ringable ring in Dove's Guide: full-circle rings of any number of bells, and mini-rings, which are marked as such. Unringable rings, chimes and carillons are not included. The list is deliberately broader than the census sampling frame, so that anyone who rings somewhere can find their tower.
